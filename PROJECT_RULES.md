# _myTodoHUB Project Rules

- This is a vanilla HTML, CSS, and JavaScript project.
- Do not introduce frameworks or libraries.
- Do not introduce npm, Node.js, TypeScript, React, Vue, Angular, Tailwind, Bootstrap, or external dependencies unless explicitly requested.
- Preserve the existing PWA manifest and service-worker functionality.
- Keep the app functional offline.
- Use `localStorage` for current todo data unless another storage system is explicitly requested.
- Prefer small, focused changes.
- Do not rewrite working files unnecessarily.
- Explain proposed changes before making large architectural changes.
- Keep the application mobile-first and accessible.
- Test after significant changes.
- Do not remove existing functionality when adding new functionality.
- Keep the project lightweight for mobile devices.
